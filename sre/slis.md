# Service Level Indicators (SLIs)

## What is an SLI

A Service Level Indicator measures system performance from a user's perspective.

## Common SLIs

### Availability

Percentage of successful requests.

Example:

99.95%

### Latency

Response times.

Examples:

- p50
- p95
- p99

### Throughput

Requests per second.

### Error Rate

Percentage of failed requests.

## Example

Availability:

99.95%

Latency (p95):

< 300ms

Error Rate:

< 0.1%
